Manage Stripe Connect accounts for each tenant. Each tenant has its own Stripe account (Standard) — they own the funds, taxes, and customer-facing payment flows. Onboarding opens a Stripe-hosted form for KYC and bank setup.

Link an existing Stripe account

If a Stripe Connect account was already created directly in the Stripe dashboard (rather than via "Continue Onboarding" below), paste its account ID here to attach it to the studio37 tenant. This does not create a new account.

Sync products to Stripe

New and edited products now sync to Drew's connected Stripe account automatically (as real Products + Prices, so he can find and charge for them from the Stripe Dashboard app or build Payment Links during in-person sales). Use this button to backfill products that existed before Stripe was connected, or to retry any that failed to sync. Safe to re-run — it updates existing Stripe products instead of duplicating them.

Import historical Stripe payments

New in-person payments (Tap to Pay, or anything collected directly in the Stripe Dashboard app) are captured automatically going forward. Use this button to pull in any sales from the last 90 days that happened before that was wired up, or if one was ever missed. They'll show up in Orders marked Complete. Safe to re-run \u2014 it never creates duplicates.
